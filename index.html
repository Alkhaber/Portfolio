03 / AI Agent
Python · LLMTavilyReportLab
Investor Report Generator
A learning project I built to understand how AI agents work. You give it a one-sentence startup idea, it plans its own web searches for market data, competitors and risks, writes a structured analysis and exports it as a designed PDF. The most interesting part was a design problem: AI output is unpredictable, so I made every section of the brief use a fixed tag that the layout reads. It is an experiment, not a finished product, and the investment score is the model's estimate rather than a real financial model.
Learning project · 2026

05 / AI Agent
Python · LangGraphGroq LLMStreamlit
Football Live Agent
A learning project where I explored agent frameworks through something I follow closely: football. A LangGraph agent checks live matches and sports news every minute, spots new goals by comparing each update with the previous one, and lets an LLM classify every event by type and severity. Important events go to a Slack alert and a Streamlit dashboard. Built to learn how agents keep state and make decisions, not as a finished service.
Learning project · 2026
